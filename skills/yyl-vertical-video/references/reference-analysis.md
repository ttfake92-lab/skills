# 参考片逐帧拆解（2026-10-29）

两条参考片：A `2115254125080535504.mp4`（118.4 s，1080×1920，23.976 fps，2.3 Mbps），B `2113794050578862456.mp4`（134.2 s，25 fps，2.0 Mbps）。同一位英文创作者、同一套模板。方法：2 fps 联系表通看全片（A 236 帧、B 268 帧），关键帧取原尺寸量坐标，左边距亮度判断分屏 / 全屏，ebur128 量响度。

## 1. 画面分区

```
y 0     ┌──────────────────────────┐
        │  分段标题（两行）          │  y ≈ 110–260
        │                          │
        │  动效区：一次一个部件       │  y ≈ 300–1180
        │                          │
y 1265  │        字幕（1–3 词）      │  ← 在人物头顶正上方
y 1300  │      ╭──头──╮             │  ← 人物抠像冲出卡片
y 1410  │ ╭────┤ 人物 ├──────────╮  │  ← 圆角人物卡顶边
        │ │ 房间背景（被裁在卡片里）│  │
y 1920  └─┴────────────────────────┴─┘  ← 卡片出画，不见底边圆角
```

- **人物卡**：x 72–1008（宽 936），顶边 y≈1410，圆角约 34，底边出画。卡片里是原片房间，人物从肩部到画面底。
- **人物出框（重点）**：人物是抠出来的，比卡片里的房间大一圈（约 1.12–1.18 倍），以卡片底部为锚放大，所以帽顶冲出卡片上沿约 100–110 px（帽顶 y≈1300），手势也会伸出卡片左右边。背景房间的上半部分被卡片顶边「往下裁掉」，人物的上半部分却留在卡片外 —— 前景比背景大、又越过了边框，一眼就有纵深。人物下方有一圈很淡的阴影压在房间上。
- **全屏人物**：同一机位直接放大到 1080×1920（脸占画面中上部），字幕在胸口 y≈1250。A 约 17% 时长全屏，B 约 10%；每次 0.5–5 s。

## 2. 节奏

| 量 | A | B |
|---|---|---|
| 分屏 → 全屏次数 | 10 | 14 |
| 全屏单次时长 | 0.5–4.8 s | 0.25–2.8 s |
| 动效区换状态 | 每 1.5–3 s（新卡片、新一项、新连线） | 同 |
| 字幕换块 | 每 0.3–0.6 s（1–3 个英文词） | 同 |
| 分段标题 | 每段一个，段内不变 | 同 |

全屏出现在：开场钩子后的第一句判断、每个方法讲完后的「解释 / 吐槽」、CTA（片尾「Comment "books"」）。

## 3. 标题与字幕

- 分段标题两行：上行粗无衬线（白），下行斜体衬线（"Boring Content *Addictive?*"、"*Killer* Hook"），关键词下有一道深红下划线。逐词模糊 → 清晰入场；换段时整体模糊退场，新标题再进。编号段落直接写「1. New Reveal」「2. Contrast Framing」「3. Urgency」。
- 字幕：白色粗无衬线约 60 px，无底板，只有柔和投影；1–3 个词一块，几乎逐词换。CTA 时把关键词换成斜体衬线大字（"*books*"）混排。

## 4. 动效部件（按出现顺序）

| 部件 | 片段 | 做法 |
|---|---|---|
| 竖版视频卡 | A 0–1 s | 一张小竖屏卡片（B-roll）居中，开场即有画面 |
| 白色光圈 + 剪影 | A 1–4 s、44 s | 白色圆盘发光，人物侧脸剪影，大脑部位红色发光 |
| 清单玻璃卡 | A 3–4 s | 4 行图标 + 文字；未说到的行模糊，说到的行变清晰、变红 |
| 中心节点 + 曲线 + 选项卡 | A 7–15 s，B 10–20 s | 左侧深红圆节点，曲线连到右侧 4 张深色选项卡；当前步骤的卡片点亮，其余模糊 |
| 对比文档 | A 16–40 s | 深色文档卡打字机输入；「Old Advice / New Reveal」两张并排，旧的变红、新的变绿 |
| 数据卡 | A 15–18 s | 黄色小标签 + 大字结论 + 红色关键词 + 小号数字 |
| 仪表盘 | A 70 s | Normal → Maximum Impact 半圆表，指针打到红区，下方红色发光按钮 |
| 缩略图环绕 | A 72–75 s | 一圈竖版缩略图环绕剪影，飞入中心 |
| 3×3 网格 | A 77 s | 红按钮在中心，四周格子写着前面讲过的方法 |
| 手机墙 | B 6–20 s | 2×2 手机框里播放真实短视频，右下角绿色 / 红色状态点 |
| 浅色段落 | B 70–90 s | 背景换成浅灰，标题变黑，用于「Show Proof」示例 |
| 地图 / 数据片尾 | B 130 s | 浅色背景上一张深色卡片：视频截图 + 播放量 |

共同点：所有部件都从**模糊 + 略小**变清晰入场（约 0.3 s），列表逐项错开 0.1–0.15 s；不用的信息直接**模糊处理**（既是聚焦也是隐私）；一屏只有一个主角部件。

## 5. 颜色、质感、声音

- 背景纯黑到 `#0B0B0B`，有极淡的方格网格；B 有一段浅灰 `#E6E6E6` 主题。
- 主色深红（≈ `#C8102E`），辅色只有绿色（状态 / 正确）和黄色（小标签）。
- 卡片是深灰半透明「玻璃」，细白描边，大阴影。
- 响度：A −16.9 LUFS，B −19.1 LUFS；峰值贴 0 dBFS。人声为主，动效出场有轻 UI 音效。

## 6. 本 Skill 的取舍

- 照搬：分区、人物卡尺寸与出框、分段标题双字体 + 红下划线、模糊入场、逐项变红、中心节点连线、手机墙、全屏打断节奏；卡片做成液态玻璃质感（参考片的文字底板有苹果液态玻璃式的模糊折射和高光边）。
- 改动：中文没有斜体，下行标题用宋体 Black 加 0.2 斜切；字幕按中文改成 2–8 字一块；码率提到 20 Mbps（参考片 2 Mbps 是平台二压后的）；响度统一 −16 LUFS、峰值 ≤ −1 dBTP。
- 没照搬：浅色主题段（全片保持深色，浅色段视觉太跳）；无衬线字体（全部换成衬线，重点标题纵向拉高）；参考片的具体文案、图标与配色值以外的设计；所有部件都是代码重画的。
