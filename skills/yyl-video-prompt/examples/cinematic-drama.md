# 电影精品档示例

慢节奏、靠表演推进的剧情戏。档位规则见 [modes/cinematic-drama.md](../modes/cinematic-drama.md)。

- **完整示例**：《改名》——从用户脚本到能直接提交的成品
- **表演片段**：只演示【分镜时间轴】里的表演写法，可以直接搬进完整提示词

示例里的素材引用用通用写法「图片N」。落到具体工具时，按 [tool-adapters.md](../references/tool-adapters.md) 替换（LibTV 换成 `{{Node "节点名"}}`）。

## 完整示例：《改名》——单段 30 秒三人对手戏（纯文生）

> **用户原始脚本**：第七幕，县城家里，主人公和父亲吵起来，母亲沉默。主人公说：「我就是要改名！你现在凭什么管我，你们早就说了只养我到 18 岁。现在大学生活费也是我自己挣的。」父亲拍桌子：「你敢改名，以后就别回来了。」母亲过来安慰，没有说话，只是抱着主人公。
>
> **导演判断**：同一地点的连续冲突，不拆段，30 秒一段。小夏在这个环境里不会落泪，只有愤怒和硬顶。镜头一、四以动作为主，轻量写；镜头二、三是表演时刻，按八维细写。

## 段1：饭桌上的改名冲突（0–30 秒）

档位：电影精品
生成模式：纯文生
模型参数：Seedance 2.5 | 720p | 21:9 | 30s
参考素材：无。三人外貌写在【人物一致性】里。要做系列或多段，先出三人定妆图，再改走多图参考。

提示词：

```text
【全文地图】
生成一支 30 秒、写实电影质感的家庭剧情短片，原生同步中文对白，21:9 宽银幕。故事发生在中国县城普通家庭的饭厅，
傍晚。这不是一场哭诉，而是一次长期压抑后的正面冲突。小夏在这个家里不会落泪，她的情绪只有愤怒和硬顶。
镜头保持安静，主要依靠演员面部、呼吸、目光和声音完成推进。

【人物一致性】
小夏：20 岁，大学生，短发，穿旧灰色连帽卫衣，坐姿前倾，背绷直。面部干净，眼神直接，没有妆容修饰。
声音是年轻女声，语速快，情绪硬。
父亲：50 岁，县城工人，身材结实，短发，穿深色旧工装衬衫，袖口卷起，手背有劳作痕迹。声音低沉，带一点沙哑，
平时话不多，被顶撞后爆发。
母亲：48 岁，穿浅色旧家居服，头发随意挽起，坐在侧边。不主动参与冲突，但一直在场。
三人始终保持相同面孔、年龄、服装、发型和站位，人物不得模仿任何现实演员或公众人物。
遵守 180 度轴线：小夏位于空间右侧，父亲位于空间左侧，母亲位于后景偏左，三人视线始终准确对接。

【道具】
旧木桌上摆着家常饭菜、三副碗筷。小夏开场把筷子搁在碗上；父亲拍桌时碗和筷子被震得跳动。

【场景与空间】
中国县城普通家庭的饭厅。旧木桌居中，白炽吊灯悬在桌子正上方，墙上挂着挂历，后景是旧木柜，窗外是邻楼灰墙。
傍晚光线偏暗偏暖，从画面左侧窗户照入。小夏和父亲隔着桌子相对而坐，母亲坐在后景偏左、靠近父亲的位置。
三人都坐在木椅上，前臂搭在桌沿。

【风格与画质】
写实电影摄影，24fps 观感，轻微 16mm 胶片颗粒，50mm 与 85mm 定焦镜头。整体色彩克制，以暗棕、灰褐、
低饱和黄色为主；白炽吊灯是唯一的人工光源，与左侧窗光形成冷暖对比。美术朴素陈旧，不做过度干净的布置。

【分镜时间轴】
【镜头一｜0.0–4.0秒】
50mm 标准镜头，中景，小夏和父亲隔着旧木桌对坐，母亲在后景偏左低头。摄影机略微偏小夏一侧，三分法构图，
背景是旧木柜和窗户。固定机位，只保留非常轻微的手持呼吸感。
开始时，三人正在吃饭。小夏突然把筷子往碗上一搁，动作不重，但很干脆。父亲抬头看她，嘴里还在嚼饭，动作停住。
母亲没有抬头，但捏筷子的手指紧了紧。
小夏直视父亲，AU4 眉毛下压、AU7 眼睑收紧、AU23 嘴唇收紧。她背挺直，肩膀没有缩，声音从压抑直接抬起来：
「我就是要改名。」
最后一个字落下后硬切，不做淡入淡出。

【镜头二｜4.0–16.0秒】
切换到小夏胸部以上近景，三分之二侧脸朝向画面左侧。背景虚化，只有旧木墙和一盏昏黄的灯。镜头基本固定，
随着她情绪升级，摄影机做几乎察觉不到的缓慢推近。
4.0–7.0 秒：她立刻接住自己的话，前臂压住桌沿，身体突然向前倾几厘米，下巴推出。眉毛用力下压，眉间形成深沟；
眼睛睁大紧盯父亲，鼻翼微微张开；嘴唇从紧闭变成快速发音。她不是单纯发怒，而是在宣告独立。
「你现在凭什么管我？」
说到「凭什么」时，她的右手短促拍了一下桌面，动作不能夸张，只有一次。
7.0–11.0 秒：她没有后退，仍然直视父亲。眉心仍然紧皱，但语速更快，声音更硬。她开始翻旧账，语气不是委屈，是算账。
「你们早就说了只养我到 18 岁。」
说到「18 岁」时，头部向父亲方向用力一点。
11.0–16.0 秒：愤怒继续升级，但没有裂缝。AU4 保持 C 强度，AU7 收紧到 C，AU25/AU26 在关键词处快速增强。
声音一句比一句高，每个字咬得很清楚，尾音不收。
「现在大学生活费也是我自己挣的。」
「我自己」三个字加重。她没有哽咽，没有眼眶发红，只有火气。最后 0.5 秒，她嘴唇抿成一条线，胸口起伏，硬切。

【镜头三｜16.0–24.0秒】
硬切到父亲近景，与镜头二对称的反打：同焦距、同光线，父亲三分之二侧脸朝向画面右侧。小夏的声音在画外继续，
但镜头只拍父亲。
16.0–19.0 秒：父亲最初仍保持被顶撞后的僵硬。他放下筷子，AU4 眉毛下压、AU7 眼睑收紧、AU23 嘴唇收紧。
他盯着小夏，下颌肌肉咬紧，像在想怎么压回去。
19.0–21.0 秒：他突然右手拍桌，手掌整个落下，碗和筷子震动。拍桌瞬间 AU4 到 C、AU7 到 C、AU25/AU26 快速增强到 D，
鼻翼张开，颈部肌肉收紧。但这不是失控咆哮，而是权威被挑战后的反击。他说，声音压低但每个字很重：
「你敢改名，」
21.0–24.0 秒：他身体向前探出，左手撑住桌沿，AU4 保持 C，AU7 保持 C，眼神没有移开。
「以后就别回来了。」
最后一个字落下后，他的手还按在桌上，指节发白。胸口起伏一次。硬切。

【镜头四｜24.0–30.0秒】
切换到三人中景。母亲双手撑着桌沿从座位上站起来，绕过父亲身后，走向小夏。她的动作很轻，头低着，
没有看父亲，也没有直视小夏。
24.0–26.5 秒：母亲走到小夏身侧，犹豫了一下，然后弯腰从侧面抱住她。
26.5–29.5 秒：小夏仍坐在椅子上，没有回抱。她的身体僵硬，肩膀仍然绷着，AU4 保持 B，嘴唇抿紧。她没有看母亲，
也没有再看父亲，目光落在桌面上某一点。母亲的脸贴着她的肩，眼眶发红，但也没说话，只是用手轻轻拍她的后背。
最后保持这个姿势约 0.5 秒，直接结束，不淡出。

【声音设计】
原生成中文对白，严格区分三位说话者，口型与每个音节准确同步。
小夏使用年轻、直接、略带锋利的女声。情绪轨迹：压抑开口 → 愤怒质问 → 翻旧账 → 硬顶摊牌。不要哭腔、哽咽和尾音发颤。
保留真实换气，但换气后声音立刻硬回来。
父亲使用低沉、沙哑、平时话不多的男中音。被顶撞后声音压低、加重，拍桌时音量短促抬高，但不是说教式咆哮。
母亲没有台词。
环境声底：饭桌上极轻的碗筷声、旧吊灯的电流声、窗外远处隐约的市井声。
事件音：0.5 秒筷子搁在碗沿的一声轻响；5 秒小夏拍桌的短促一声；19 秒父亲拍桌的闷响，碗筷震得跳起；
24 秒母亲起身时椅子腿擦地；抱住小夏时布料摩擦声和极轻的呼吸声。
不要背景音乐，不要电影配乐，不要旁白。

【硬约束】
必须严格遵守：三人全程在同一间饭厅，站位遵守 180 度轴线，视线准确对接；小夏全程没有眼泪、没有哭腔；
父亲只拍一次桌；母亲没有台词；四个镜头之间都是硬切；最后停在拥抱姿势直接结束。
不要字幕、可读文字、水印和 Logo（字幕后期加）；不要新增第四个人物；不要面孔漂移和美颜磨皮；
不要慢动作和环绕镜头；不要异常牙齿、嘴唇粘连、口型错位或目光漂移。

【核心要求】
这是一个长期被忽视的孩子，在家庭饭桌上一口气把独立性摔出来的瞬间。画面的力量来自小夏面部和声音里的硬气，
以及父亲和母亲各自的沉默反应，而不是依靠频繁运镜或剪辑。
```

段尾状态：母亲弯腰从侧面抱着坐着的小夏，父亲的手仍按在桌上，三人中景。

# 表演片段

以下是 v1 的表演写法示例，只演示【分镜时间轴】里的表演层。片段 4、5 用的是旧版外壳，时长 45 秒和 60 秒，超过了单段上限；实际生成时要按「分段」规则拆成 2–4 段，表演细节可以原样搬进新格式。

---

## 片段 1：喜悦（克制的开心）

### 用户原始需求

> 一个女孩收到好消息，很开心。

### 轻量写法（日常镜头）

```text
镜头 2 / 8–14s，中景：
- 内容：女孩放下手机，坐在床边
- 目的：她刚收到录取通知，内心喜悦但还没完全释放
- 表演：嘴角先微微上扬，眼睛亮了一下，然后深吸一口气，肩膀放松下来
- 身体：手轻轻握住手机，没有夸张动作
```

### 进阶写法（需要情绪递进）

```text
镜头 2 / 8–18s，特写女孩面部：

时间段：8–18s
人物目的：她反复确认消息是真的，然后让喜悦慢慢释放出来
情绪变化：怀疑 → 确认 → 喜悦涌现 → 试图克制 → 忍不住笑出来
台词触发词：无台词，由手机屏幕内容触发

面部动作与 AU：
- 8–10s：AU1 眉毛内侧轻微抬起（A），AU5 上眼睑抬起（B）——怀疑/确认
- 10–13s：AU6 脸颊抬起（B），AU12 嘴角上扬（B）——真笑开始
- 13–16s：AU12 增强到 C，AU6 增强到 C——喜悦扩大
- 16–18s：她用手捂住嘴，AU12 减弱到 B，但 AU6 保持——试图克制

目光与身体：
- 先看屏幕，再抬眼看天花板 0.5s（消化消息）
- 然后低头笑，肩膀轻微抖动
- 最后用手捂嘴，身体微微前倾

声音、呼吸与停顿：
- 深吸一口气
- 发出很轻的一声"啊"
- 然后笑出声但立刻用手捂住

结束状态：
- 捂着嘴，眼睛弯起来
- 静止 1s，胸口还在轻微起伏
```

## 片段 2：恐惧（从警觉到失控）

### 用户原始需求

> 一个人半夜听到门外有声音，很害怕。

### 正确写法

```text
镜头 3 / 0–12s，特写人物上半身：

时间段：0–12s
人物目的：他/她想确认门外声音，同时压抑恐惧
情绪变化：警觉 → 紧张升级 → 恐惧突破 → 僵硬

台词触发词：无台词，由门外声音触发

面部动作与 AU：
- 0–2s：AU1 眉毛内侧抬起（B），AU5 上眼睑抬起（B）——警觉
- 2–5s：AU7 眼睑收紧（B），AU4 眉毛下压（A）——紧张
- 5–8s：AU5 快速增强到 D，AU20 嘴唇横向伸展（B）——恐惧突破
- 8–12s：AU5 保持 D，但面部整体僵硬，呼吸变浅

目光与身体：
- 头转向门方向
- 肩膀僵硬，脖子微微前伸
- 一只手不自觉地抓紧床单
- 身体从坐姿慢慢变成紧绷的静止

声音、呼吸与停顿：
- 呼吸从正常变浅、变快
- 喉咙动了一下，像要喊但没出声
- 最后屏住呼吸 2s

结束状态：
- 全身僵硬，只有眼睛在转动
- 静止 2s，等待下一次声音
```

## 片段 3：厌恶（身体比脸先反应）

### 用户原始需求

> 一个人听到虚伪的恭维，露出厌恶。

### 正确写法

```text
镜头 4 / 6–14s，近景：

时间段：6–14s
人物目的：他/她要保持礼貌，但忍不住流露厌恶
情绪变化：礼貌倾听 → 内心反感 → 短暂失控 → 重新掩饰

台词触发词：对方说完恭维话的瞬间

面部动作与 AU：
- 6–8s：维持礼貌微笑，AU12 轻微（A）
- 8–9s：AU9 鼻子轻微皱起（A），AU10 上唇轻微抬起（A）——厌恶闪现
- 9–11s：迅速压下，AU12 重新上扬但不够自然
- 11–14s：看向别处，AU4 轻微下压（A）——礼貌性忍耐

目光与身体：
- 听的时候看着对方
- 厌恶闪现时头微微后仰 2cm
- 随后目光移向旁边，肩膀轻微后收
- 手指在桌面上轻敲一下

声音、呼吸与停顿：
- 对方说完后，没有立刻回应
- 停顿 0.8s
- 然后说"谢谢"，声音比平时轻且平

结束状态：
- 嘴角保持礼貌上扬，但眼神冷淡
- 手指停止敲击，手握成拳又松开
```

## 片段 4：双人对手戏（反应链）

### 用户原始需求

> 一对情侣吵架，女方指责男方不在乎她。

### 完整写法

```text
【全剧控制】
时长：45s，横屏 16:9
场景：傍晚厨房，暖光，两个人站在餐桌两侧
人物：A（女，28岁，穿灰色毛衣）；B（男，30岁，穿深色衬衫）
影像风格：现代都市剧情片，自然光，轻微手持感

【镜头时间轴】
镜头 1（0–10s）：中景双人，A 质问 B
镜头 2（10–28s）：特写 A，情绪递进
镜头 3（28–38s）：特写 B，反应
镜头 4（38–45s）：中景双人，A 转身离开

【表演控制】

镜头 1 / 0–10s：
- A 把盘子重重放在桌上，双手撑住桌面
- 她直视 B，身体前倾
- 台词："你今晚又忘了，对吗？"
- 表演：愤怒但还在控制，AU4 眉毛下压（B），AU7 眼睑收紧（B），AU23 嘴唇收紧（B）

镜头 2 / 10–28s：
- 时间段：10–28s
- 人物目的：A 想让 B 承认错误，但逐渐意识到他不会
- 情绪变化：愤怒 → 委屈浮现 → 愤怒保护 → 裂缝 → 失望
- 台词触发：
  - "你" — 音量高，直视
  - "又忘了" — 重音在"又"
  - B 沉默后，A 停顿 1.2s
  - "对吗" — 声音变轻，尾音微颤
- 面部动作与 AU：
  - 10–14s：AU4（B），AU7（B），AU23（B）——愤怒质问
  - 14–18s：AU1 轻微抬起（A），AU15 嘴角下沉（A）——委屈渗入
  - 18–22s：重新压下委屈，AU4 回到 B，AU7 收紧
  - 22–25s：B 沉默，A 眼睛闪烁，AU1 增强到 B
  - 25–28s：AU15 下沉到 B，声音变轻
- 目光与身体：
  - 前段直视 B
  - 中段目光下移 0.5s，又强迫自己看回去
  - 后段肩膀下沉，身体从前倾收回
- 声音、呼吸与停顿：
  - 前两句音量高
  - B 沉默时，A 短促吸气
  - "对吗"变轻，尾音破掉
- 结束状态：嘴唇微张，眼眶红但没流泪，静止 1s

镜头 3 / 28–38s：
- 时间段：28–38s
- 人物目的：B 想解释，但发现任何话都苍白
- 情绪变化：防御 → 愧疚 → 无力
- 台词触发：A 的失望表情
- 面部动作与 AU：
  - 28–31s：AU4 下压（B），AU23 嘴唇收紧（B）——防御
  - 31–34s：AU1 眉毛内侧抬起（A），AU15 嘴角下沉（A）——愧疚
```
