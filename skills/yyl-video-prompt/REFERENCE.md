# yyl-video-prompt 共用手册

> 两个档位都适用的写法。档位特有的结构和规则在 `modes/`：
> [短视频档](modes/short-video.md) · [电影精品档](modes/cinematic-drama.md)。按需查，不用通读。

## 一、Skill 的边界

处理所有「把内容变成 AI 视频提示词」的活：

- **人物戏**：日常动作、对话、情绪递进、内心戏、对手戏、群戏
- **非人物戏**：空镜、产品、风景、动物/机器人等角色
- **输入形态**：完整脚本、故事梗概、口播稿、分镜表、一句话想法（一句话 → 单段，直接补全）

不处理：当前项目已有专用工作流的内容（Vlog、情感钩子、新闻解说等专用 Skill 优先）；纯图片提示词。

原则：**日常动作轻量写，关键时刻细写，AI 容易出错的地方重点写。**

## 二、分段：把脚本拆成生成单元

一段 = 一次生成 = 一条独立成片。视频工具单次时长有限，所以先切段再写。

### 切分边界

| 信号 | 例子 |
|---|---|
| 地点变化 | 书房 → 街道 |
| 明显时间跳跃 | 白天 → 深夜 |
| 情绪大转折 / 故事节拍 | 平静 → 冲突爆发 |
| 主体或视角切换 | A 的视角 → B 的视角 |
| 超过单段时长上限 | 45 秒的戏 → 15 + 15 + 15，或 30 + 15 |

- **不要过度切分**：同一地点的连续动作就是一段，段内可以多镜头或一镜到底。
- **不要切太粗**：一段塞下两个不相干的场景，会超出单次生成能力。

### 段长

| 内容 | 建议段长 |
|---|---|
| 表演密集（对白、情绪转折、对手戏） | 10–15 秒。动作预算紧，模型执行更准 |
| 多分镜叙事、流动叙事、空间巡游 | 可到工具上限（Seedance 2.5 = 30 秒） |
| 钩子、单个镜头 | 5–15 秒 |

各工具上限见 [tool-adapters.md](references/tool-adapters.md)。镜头数按档位定，见 `modes/`。

### 段与段的衔接

- **段尾状态**：每段结尾写清姿势、位置、手里拿着什么、构图、光线。下一段开头从这个状态起。
- **尾帧接力**：能把上一段尾帧当下一段的首帧或参考图，就写进参考素材（「图片2：上一段尾帧，锁定人物位置和姿势」）。
- **切点设计**：动作做到一半硬切（下床只完成一半就黑场），比做完再切更好接。
- **每段自包含**：生成工具没有跨段记忆。人物锁定、场景、光线、道具状态每段都写全，不写「同上」「沿用上一段」。只有外貌交给参考图锁。

## 三、参考素材绑定

### 一张图只承担一个任务

| 图的任务 | 锁定什么 | 通常排除什么 |
|---|---|---|
| 人物身份 | 脸、发型、肤质、五官比例 | 图里的背景；另有服装图时排除服装 |
| 服装造型 | 服装、鞋包、配饰、全身比例 | 背景 |
| 首帧 | 构图、人物位置、姿势、光线——视频从这一帧开始 | — |
| 尾帧 | 结束构图和姿势 | — |
| 场景视觉基因 | 空间布局、光线方向、色温、材质 | 图里的人物 |
| 道具 | 外形、颜色、材质、手持比例 | 背景 |
| 状态图 | 同一角色的不同状态（如机器人 LED 屏的「害怕」「思考」各一张） | — |
| 参考视频 | 动作、运镜节奏、手持幅度 | 视频里的人物身份 |
| 参考音频 | 声线、口音、语速 | — |

### 写法

1. **先在参考列表定义，再在【参考绑定】写一句总绑定**：「图片1 是丹眉的人物身份和睡衣造型参考，脸、短黑波波头、红色发饰完全锁定图片1」。
2. **动作发生处再点名**：「她拿起图片3的手机」「首帧严格匹配图片2」「LED 屏切换为图片4的白色思考表情」。
3. **不写「参考图片」「参考上传素材」**：模型不知道锁什么。
4. **素材越多不代表越稳**：只放这一段真正需要的。
5. **引用语法跟工具走**：LibTV 必须 `{{Node "节点名"}}`，见 tool-adapters.md。

### 有图时，文字写什么

外貌交给图锁，文字只写**图里看不出来的东西**：声音、习惯动作、站位、此刻的状态（头发微乱、衬衫湿了）。文字里再描述一遍长相衣服，会和参考图打架。

### 用户没给图

- 在参考列表写清每张图应该是什么：「图片1：丹眉正面半身照，白底，短黑波波头＋红色发饰，五官清晰」。用户去准备，或者先出定妆图。
- 或者改纯文生：外貌、服装全部写进人物块。
- 要做系列或多段：**先出定妆图**，确认后再写视频段。人物错了后面全废。

## 四、共用块写法

### 道具

关键物件单独交代——这是连贯性最容易丢的地方。

- 写**样子 + 状态 + 和人物/事件的关系**：不是「一把枪」，而是「插在枪套里的左轮，枪身有磨损划痕」。
- 状态变化写进时间轴：「4 秒，她把手机扔到床上，屏幕朝下」。
- 没有影响画面或剧情的物件，就省略这一块。

### 场景与空间

具体到能「闻到」：不是「一个房间」，而是「午后阳光透过百叶窗洒进书房，灰尘在光柱里漂浮」。

必须交代的空间结构：

- **地理位置**：人物在人行道上，不在马路上；护栏外才是马路和电车
- **主体位置**：谁在画面左右、前后景
- **纵深层次**：前景 / 中景 / 远景分别有什么
- **人群车流**：密度和流动方向（「至少 20–30 个路人在前中远景同时流动」）
- **光线来源**：从哪个方向来（「从画面左侧窗户照入」）

### 风格与画质

先定基调，再选词。词库见 [cinematic-vocabulary.md](references/cinematic-vocabulary.md)。

**电影摄影基调**：

- 风格核心：1–2 个风格关键词（原子朋克、黑色电影、王家卫）
- 视觉基调：具体摄影机 + 镜头 + 效果，如「IMAX 胶片摄影机 + Panavision C 系列镜头（动态模糊）」——不要只写「电影质感」
- 色彩与影调：具体色彩方案（不是「温暖」而是「复古暖橙 + 海盐蓝高对比」）、胶片颗粒、光线方向、明暗关系、画幅
- 风格参考（可选）：导演或作品，最多 1–2 个

**手机实拍基调**（Vlog、钩子、生活记录）：

- 第一句交代**拍摄者是谁**：「男朋友用手机横着随手拍下」——模型就知道镜头是个人，会对镜头笑、躲、踢，或完全不理镜头
- 手持写成**具体现象**：呼吸晃动、走路颠簸、构图微斜、自动对焦偶尔拉一下。只写「手持」会得到稳定器一样顺滑的运镜
- 画质缺陷：暗部噪点、轻微压缩感、高光溢出、对焦略软
- 光写成**物理现象**：「闪光灯常亮直打，离镜头越近越亮，背后暗成一片」
- **不写**「电影感 / 高清 / 大片 / 4K / 精修 / 氛围感」

## 五、时间码与动作

### 时间码规则

- 时间窗连续、不重叠
- 一个窗口只承载**一个核心动作和一个主要机位变化**
- 关键事件写到具体秒：「第 6 秒，黑西装路人从前景右侧横切擦镜，完全遮挡 0.5 秒」
- 重要动作写出**结束状态**
- Seedance 2.5 基本按秒执行，误差约 0.5 秒，**最后一拍容易偏晚**——收尾动作别压在最后 0.5 秒

镜头规格的常见写法：

| 要素 | 常见写法 |
|---|---|
| 焦距 | 35mm / 50mm / 85mm / 长焦 |
| 景别 | 大远景、全景、中景、近景、特写、大特写 |
| 机位 | 平视、俯视、仰视、过肩、侧拍、腰部以下高度 |
| 运动 | 固定、轻微手持呼吸感、缓慢推近、迎面退拍、跟拍 |
| 景深 | 浅景深虚化背景 / 深景深看清环境 |
| 构图 | 三分法、居中、对称、三分之二侧脸、前景遮挡 |

速查表见 [shot-catalog.md](references/shot-catalog.md)。

### 动作的物理精度

不是「角色很害怕」，而是「双手缓缓抬至下巴前方呈防御姿态，身体微微发抖，重心下沉」。

- **支撑点**：每个受力部位写清——背靠什么（扶手、靠背、墙）、臀部坐在哪、脚踩在哪、头靠在哪。后仰必须有等角度的支撑物。视频提示词里再写一句「全程背靠着 X」，防止动作中飘起来
- **前因后果**：谁的动作引出下一个动作，动完身体回到哪（踢完脚收回踩回坐垫；从抱枕上腾出一只手去捂镜头）
- **解剖级姿态**：哪条大腿压在哪个膝盖上、哪只脚悬空、哪只脚踩地、脚碰不碰家具
- **首帧 = 动作发生前的状态**：要第 2 秒架腿，首帧就是双腿并拢
- **身体细节**：重心、手的位置、视线、呼吸、衣料摩擦、物体运动路径

### 对白嵌入

不要把所有台词单独贴在最后，要按时间码嵌进动作和表情里：

```text
4.0—7.0 秒：
- 她突然向前倾，前臂压住桌沿
- 她说：「你现在凭什么管我？」
- 说到「凭什么」时右手短促拍了一下桌面
```

分不清说话人时，可用清晰标记：`{主角：今天真的比我想的冷。}`。

## 六、声音设计

| 要素 | 写什么 |
|---|---|
| 对白语言 | 中文 / 英文 / 粤语 |
| 音色 | 年轻女声、低沉男中音、沙哑女声 |
| 情绪轨迹 | 压抑 → 爆发 / 愤怒 → 裂缝 → 悲伤 |
| 口型 | 口型与每个音节准确同步 |
| 环境声底 | 先铺底：电脑风扇低频嗡嗡、远处城市夜声、碗筷声、虫鸣 |
| 按秒事件音 | 「第 6 秒黑西装路人皮鞋和衣料擦肩声」「19 秒拍桌闷响，碗筷震动」 |
| 收音距离与清晰度 | 远距离街拍对白应该模糊：「她的电话声被街道声淹没，只能感觉有人在打电话」 |
| 禁止项 | 默认：不要背景音乐、不要配乐、不要旁白；用户要求才加 |

声音要像画面一样具体。环境声标记可写成 `<远处地铁进站声>`。

## 七、硬约束

约束是生产控制，不是装饰。**先用正面句写死要什么，再对已知失败写短否定。**

### 正面写死（必须严格遵守）

| 类别 | 写法 |
|---|---|
| 比例 | 「丹眉全身从头到脚完整可见，只占画面竖向 1/3 到 1/2，不推近到胸以上」 |
| 空间逻辑 | 「丹眉始终在人行道上，电车出租车只在护栏外的马路远景」 |
| 动作顺序 | 「动作顺序必须是惊醒、找手机、看消息、半下床硬切」 |
| 表演尺度 | 「表演真实日常，克制」 |
| 连续性 | 「首帧严格匹配图片2」「人物身份全程匹配图片1」「全片服装不变」 |
| 遮挡 / 变装时机 | 「变装只发生在路人擦镜遮挡的瞬间」 |

### 短否定（只针对已知失败）

常用：不要字幕、可读文字、水印、Logo（字幕后期加）；不要面孔漂移、服装或发型变化；不要美颜磨皮；不要异常牙齿、嘴唇粘连、口型错位、目光漂移；不要新增人物；不要慢动作、环绕镜头。

注意：

- **否定物件清单会把被否定的东西再念一遍**，往往起反作用。不要罗列「不要出现 X、Y、Z 物件」，改成正面写「画面里只有 A 和 B」。镜头和行为约束（不合并镜头、不慢镜头）写成否定句没问题。
- 负面指令**集中写在【硬约束】**，不要散落到每个镜头。
- 合成 / 编辑类任务不写否定清单（见 tool-adapters.md）。

## 九、质量红线

- ❌ 单段时长超过工具上限
- ❌ 写「同上 / 沿用上一段」，段不自包含
- ❌ 参考图只写「参考图片」，没写锁定什么
- ❌ 人物姿态没有支撑点；动作没有前因后果
- ❌ 孤立情绪标签：「她很悲伤」；情绪直接跳跃，没有过渡
- ❌ 台词和表情脱节（台词单独贴在最后）
- ❌ 缺少硬约束，导致 AI 跑偏
- ❌ 手机实拍写「电影感 / 4K / 大片」；电影基调只写「电影质感」不写设备
- ❌ 风格堆砌（同时引用 5 个风格）；运镜与情绪不匹配（温柔场景用甩镜）
- ❌ 档位用错：短视频用了八维 + AU 的慢写法，或精品剧用了 2 秒一镜的碎切
