# 电影精品档

> 慢节奏、靠表演推进的剧情戏：精品短剧、剧情短片、文艺片段落、对手戏。
> 镜头安静，力量来自演员的面部、呼吸、目光和声音。这是 yyl-video-prompt v1 的核心方法（八维公式、AU、情绪递进）。

## 适用

- 有台词、有情绪转折、有对手戏的剧情段落
- 单镜 4–12 秒，固定机位或几乎察觉不到的缓慢推近
- 判断标准：如果把表演删掉这场戏就不成立，就用本档

不适用：节奏快、靠事件和运镜推进的短视频 → 短视频档。

## 节奏

| 段长 | 镜头数 | 说明 |
|---|---|---|
| 10–15 秒 | 1–3 镜 | 一个情绪转折 |
| 30 秒 | 3–5 镜 | 一场完整冲突（如《改名》4 镜） |

镜头少，每镜里的**子时间码**多：一个 12 秒近景可以拆 3–4 个表演节点。

## 输出结构

外壳通用（段号、档位、生成模式、模型参数、参考素材、段尾状态），档位写 `档位：电影精品`。

提示词块：

```text
【全文地图】……
【参考绑定】……（纯文生省略）
【人物一致性】……
【道具】……（没有关键道具就省略）
【场景与空间】……
【风格与画质】……
【分镜时间轴】
【镜头一｜0.0–4.0秒】……
【声音设计】……
【硬约束】……
【核心要求】……
```

道具、场景与空间、风格与画质、声音设计、硬约束的写法见 [REFERENCE.md](../REFERENCE.md)。下面是本档特有的块。

## 全文地图

用 2–4 句话讲清整段的全局信息：

| 要素 | 写什么 |
|---|---|
| 时长 | 10s / 15s / 30s（单段） |
| 画幅 | 16:9 / 21:9 / 9:16（以工具支持为准，视频工具不支持 2.39:1，用 21:9） |
| 影像风格 | 写实电影 / 文艺片 / 纪录片 / 胶片颗粒 |
| 时代 / 场景 | 90 年代县城 / 20 世纪中期美国 / 现代都市公寓 |
| 核心情绪 | 长期压抑后的爆发 / 夫妻之间的角力 / 独立宣言 |
| 整体调性 | 安静、克制、靠表情推进 / 紧张、快速、靠对白推进 |
| 最重要的表演原则 | 小夏不会落泪，只有愤怒 / 男人不是咆哮，是压住后的短促爆发 |

```text
生成一支 30 秒、写实电影质感的家庭剧情短片，原生同步中文对白，21:9 宽银幕。
这不是一场哭诉，而是一次长期压抑后的正面冲突。小夏在这个家里不会落泪，她的情绪只有愤怒和硬顶。
镜头保持安静，主要依靠演员面部、呼吸、目光和声音完成推进。
```

## 人物一致性

| 维度 | 示例 |
|---|---|
| 姓名 / 代号 | 小夏、父亲、母亲 |
| 年龄 | 20 岁、50 岁、48 岁 |
| 外貌 | 短发、身材结实、头发挽起（**有参考图时改写为「锁定图片N」**） |
| 服装 | 旧灰色连帽卫衣、深色旧工装衬衫、浅色旧家居服（有图同上） |
| 声音 | 年轻女声、低沉沙哑男中音、无台词 |
| 习惯性动作 | 背绷直、手指紧握、低头 |
| 空间站位 | 小夏在右，父亲在左，母亲在后景偏左 |
| 轴线 | 遵守 180 度轴线，视线始终准确对接 |
| 禁止项 | 不得模仿现实演员；不出现面孔漂移、服装变化、年龄变化 |

## 分镜时间轴（电影档写法）

每镜写清镜头规格（焦距、景别、机位、运动），然后按子时间码写表演：

```text
【镜头 X｜start—end 秒】
镜头规格：50mm，中景，固定机位，轻微手持呼吸感。
画面内容：人物位置、动作、环境。

start—mid 秒：
- 人物做什么（支撑点、前因后果）
- AU4 眉毛下压（B），AU7 眼睑收紧（B）
- 对白：「……」

mid—end 秒：
- 情绪变化
- AU1 眉毛内侧抬起（B）
- 对白：「……」

切换方式：硬切 / 淡入淡出。
```

- 运镜克制：固定、轻微手持呼吸感、几乎察觉不到的推近。运镜不抢表演
- 正反打保持同焦距、同光线，遵守 180 度轴线
- 对白按时间码嵌入，标出重音字和同时发生的动作（见 REFERENCE.md「对白嵌入」）

## 表演层

### 判断要不要细写

| 问题 | 答案是「是」时 | 处理方式 |
|---|---|---|
| 这里有台词吗？ | 是 | 至少绑定基础的表情、呼吸、目光 |
| 这里情绪有变化吗？ | 是 | 按时间码细拆 |
| 这里是对手戏反应吗？ | 是 | 写反应链：刺激 → 接收 → 内部处理 → 外部反应 |
| 这里是无台词内心戏吗？ | 是 | 重点写面部微表情、呼吸、目光 |
| 这里只是日常动作吗？ | 是 | 一两句话交代场景和动作 |

| 场景类型 | 处理方式 |
|---|---|
| 空镜 / 环境 / 人物走过 | 一两句话写清场景和动作 |
| 日常对话，情绪平稳 | 写人物目的 + 台词 + 基础表情 |
| 情绪转折 / 关键台词 / 对手戏 | 按时间码细拆表情、呼吸、目光 |
| 静止镜头 / 无台词内心戏 | 重点写面部微表情、呼吸、目光 |

AI 容易演假的地方：台词和表情脱节、情绪直接跳跃（突然哭、突然怒）、停顿没有原因、对手戏没有反应链、口型对不上台词。

### 情绪递进：Emotional Arc

真实表演不是情绪标签，而是**情绪状态的变化过程**。人在情绪冲击下，通常先启动防御，再逐渐崩溃：

```text
刺激 → 防御/克制 → 裂缝出现 → 保护层失效 → 真实情绪暴露 → 试图重新控制
```

示例：听到坏消息

- 0–1s：愣住，表情凝固
- 1–3s：快速眨眼，试图理解
- 3–5s：嘴角轻微抽动，想笑一下掩饰
- 5–8s：笑意消失，眼眶开始发红
- 8–12s：深吸一口气，低头，声音变轻

### 对手戏反应链

双人戏不是各演各的，要写出**刺激 → 接收 → 内部处理 → 外部反应**：

```text
B 说："你从来没有问过我的想法。"（刺激）

A 的反应：
- 接收：A 听到后肩膀微微一紧（0.3s）
- 内部处理：A 眼神闪烁，嘴唇抿了一下，在找话反驳（1s）
- 外部反应：A 压低声音说"我只是想快点决定"，但尾音没有底气
```

### AU / FACS 面部表情编码

AU（Action Unit）是脸上可被观察的动作单元。**只在关键表情处做辅助校准**，不要每个镜头都堆。

> ⚠️ AU 编码还没在实际出片里做过对照测试。模型真正读懂的，大概率是旁边的人话描述。
> AU 的价值在于逼你把表情想精确；写进提示词时必须配人话（「AU4 眉毛下压」），不要只写编码。

| AU | 动作 | 常见情绪指向 |
|---|---|---|
| AU1 | 眉毛内侧抬起 | 悲伤、痛苦 |
| AU2 | 眉毛外侧抬起 | 惊讶 |
| AU4 | 眉毛下压 | 愤怒、专注、痛苦 |
| AU5 | 上眼睑抬起 | 惊讶、恐惧 |
| AU6 | 脸颊抬起 | 开心（真笑） |
| AU7 | 眼睑收紧 | 愤怒、克制、痛苦 |
| AU9 | 鼻子皱起 | 厌恶 |
| AU10 | 上唇抬起 | 厌恶 |
| AU12 | 嘴角上扬 | 开心 |
| AU15 | 嘴角向下 | 悲伤、沮丧 |
| AU17 | 下巴抬起并绷紧 | 克制、坚定、愤怒 |
| AU20 | 嘴唇横向伸展 | 恐惧 |
| AU23 | 嘴唇收紧 | 压抑、愤怒 |
| AU25 | 嘴唇分开 | 说话、放松 |
| AU26 | 下颚下垂 | 惊讶、说话 |

强度标注：**A** 刚好能察觉 · **B** 轻微 · **C** 中等 · **D** 明显 · **E** 接近动作极限

表情三阶段：**Onset** 动作开始 · **Apex** 达到峰值 · **Offset** 逐渐消退

### 八维表演公式

对需要细写的关键片段，逐项检查：

| 维度 | 描述 |
|---|---|
| 1. 时间段 | 镜头 / 子时间码范围 |
| 2. 人物目的 | 人物此刻想做什么 |
| 3. 情绪变化 | 情绪如何过渡，保护层如何失效 |
| 4. 台词触发词 | 哪句台词、哪个词触发变化 |
| 5. 面部动作与 AU | 眉毛、眼睛、嘴唇、下巴动作 + AU 强度 |
| 6. 目光与身体 | 看哪里、身体朝向、手势、前倾/后退、支撑点 |
| 7. 声音、呼吸与停顿 | 音量、语速、停顿位置、吸气、破音 |
| 8. 结束状态与静止反应 | 说完后的状态、静止时的微反应 |

### 从观察到命名的四步

用户说不清具体动作时，带他走这四步：

1. **拆区域**：眉毛、眼睛、鼻子、嘴唇、下巴、肩膀、手
2. **观察四件事**：哪里在动、往哪个方向动、动作有多强、被什么触发
3. **用人话记录**：先用普通话写下可见动作
4. **查 AU 校准**：把关键动作对应到 AU 编码和强度

口诀：**先看见，再命名；先用人话描述，再用 AU 校准。**

### 导演式讨论模板

需要用户确认表演方向时：

```text
我对这段的判断是：______
这样处理会让观众感觉到：______
另一个可行的方向是：______
你倾向哪一种？或者你有没有更接近真实感受的描述？
```

例：「这场争吵的高潮台词是『你根本不在乎』，我打算让她的声音在这里第一次发抖，前面压低声，后面破音。这样处理你觉得对吗？」

## 核心要求

用一句话总结这场戏靠什么打动人：

```text
核心要求：这是一个长期被忽视的孩子，在家庭饭桌上一口气把独立性摔出来的瞬间。画面的力量来自小夏面部和
声音里的硬气，以及父亲和母亲各自的沉默反应，而不是依靠频繁运镜或剪辑。
```

- [ ] 每个镜头有焦距、景别、机位、运动；运镜不抢表演
- [ ] 情绪转折有保护层失效的过程，不是直接跳跃
- [ ] 关键表情有 AU 编码，并且配了人话描述；日常镜头没有堆 AU
