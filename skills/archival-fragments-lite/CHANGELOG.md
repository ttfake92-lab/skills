# Changelog

## 1.0.0 — 2026-08

从 `archival-fragments` 抽出的简版，面向公开分享。

- **不绑定任何模型或工具**。原版要求 LibTV CLI + MiniMax H3 + Fish Audio，别人环境对不上就跑偏；简版只要求「视频工具支持首尾帧」。
- **不做全自动**。去掉环境检查、配音合成、拼片脚本，只固定风格和方法。
- 保留三条硬约束：每镜参考图必须不同、具象优先、慢不等于静。第一条是真实翻过车的——有人拿一张结构图当所有镜头的参考，几十个镜头画面雷同。
- 附一条 67.3 秒成片的 35 张参考图提示词与 34 条运动句作为范例。
