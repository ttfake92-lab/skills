# 阶段 4：排节奏

早期版本写成「慢—慢—慢—爆发」加「一镜一个静止状态」，实践中被证伪：按那套写出来的镜头逐帧变化率只有参考片的 1/34，观众三秒就划走。下面是修正后的版本，来自一条 34 镜真实成片。

## 第一条：慢不等于静

参考片的慢镜逐帧变化中位数是 **1.41**；照旧版写法生成的「极慢推近」实测 **0.17**，画面几乎完全冻结。差别在于**运动的幅度**，不在速度：原片的慢镜是照片墙横跨整幅铺开、墨迹从左长到右——大幅度地慢。留白镜同样要有一个横跨画面的动作在推进。

**任何一镜，结尾画面必须和开头明显不同。** 这是唯一的硬标准。

## 第二条：节奏在剪辑台上定，不在提示词里定

这是首尾帧工作流带来的最大收益。所有素材统一生成 5 秒，剪辑时按旁白时长变速：

- 紧的地方压到 0.8–1.5 秒（钩子、并列快切）
- 常规 1.5–2.5 秒
- 收尾、转折放到 3–4.5 秒

同一条素材改时长是几秒钟的事，不用重新生成。**不要在提示词里写「快」「慢」**——写了也没用，H3 的输出时长由 `duration` 参数决定。

## 第三条：镜长由旁白算出来，不是拍脑袋

流程固定：先合成配音 → 量出每句时长 → 把该句分配给 N 个镜头 → 每镜时长 = (句长 + 气口) / N。

语速参考：Fish Audio `s2-pro` 1.1 倍速下约 **4.6 字/秒**。

**不平均分的三种情况**（成片实测有效）：

| 场景 | 分配 | 理由 |
|---|---|---|
| 开场钩子 | 62 / 38 | 第一个画面要给足时间看清，第二镜甩快 |
| 递进关系 | 40 / 60 | 后一镜是结果，要压得住 |
| 收尾 | 35 / 65 | 最后一镜留 3–4.5 秒让观众消化 |

## 第四条：黑场最多 0.5 秒

一整片最多一次，放在最重的转折点。超过 0.5 秒观感像播放器卡住。

## 第五条：音效分层

三层分开做，H3 的 `enableSound` 留空：

1. **旁白**——气声重、语速慢，每句之间 0.18 秒静音（不用自然停顿，会太长）
2. **音乐**——单层弦乐 pad，无鼓
3. **音效**——逐个物件的 foley（纸张翻动、图钉按下、硬币落盘、印章压下），不是氛围垫

参考片有 68 个瞬态点，每一个都对应画面里一个具体动作。这是「高级感」的真正来源。

## 已验证的成片参数

67.3 秒 / 34 镜 / 平均 1.98 秒一镜 / 17 句旁白 / 1 个 0.5 秒黑场 / 1920×1440。
