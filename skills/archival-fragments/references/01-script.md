# 阶段 1：想法 → 文案 → 拆故事 / 画面 / 节奏

这一阶段的产出是**一张逐镜表**。表没定下来之前，一张图都不要生成。

## 1. 想法 → 文案

用户可能只给一句话（"讲讲某公司市值第一"），也可能给一份写好的稿子。

**先说出这条片子真正的主张**，用一句话。不是"介绍某某"，而是一个**有立场的判断**。

- ✗ "介绍长鑫科技上市"
- ✓ "三点二八万亿定的不是它今天的利润，是一个空了十年的位置终于有人站上去了"

主张决定后面所有画面。没有主张，画面就会变成一堆好看但互不相干的插图。

**写文案的规矩**：

| 规矩 | 说明 |
|---|---|
| 每句 8–16 字 | 长句气口拖沓，短句才有节奏 |
| 不写长从句 | 一句话一个意思 |
| 论点不由旁白直说 | 靠结构立：给现象 → 否定它 → 建立对立面 → 回扣 |
| 总字数 ≈ 目标秒数 × 4 | 4.6 字/秒（1.1 倍速）再留气口 |

写完把文案给用户看一遍。这一步改很便宜。

## 2. 文案 → 配音 → 量时长

**必须先配音再拆镜**，因为镜长由每句配音的真实时长决定，不是估的。

把文案切成句，写 `narration.json`：

```json
{
  "model": "s2-pro",
  "speed": 1.1,
  "gap_seconds": 0.18,
  "black_seconds": 0.5,
  "lines": [
    {"id": "N01", "text": "三点二八万亿。"},
    {"id": "N02", "text": "这是长鑫科技上市当天的收盘市值。"},
    {"id": "BLACK", "text": null},
    {"id": "N03", "text": "十年前，这个位置是空的。"}
  ]
}
```

`text` 为 `null` 的是黑场占位，**一整片最多一个，最长 0.5 秒**，放在最重的转折点。

逐句合成（串行），然后量时长：

```bash
set -a && source .env && set +a
python3 -c "
import json
for l in json.load(open('narration.json'))['lines']:
    if l['text']: print(l['id'] + '\t' + l['text'])
" > /tmp/lines.tsv

while IFS=$'\t' read -r id text; do
  [ -f "narration/$id.wav" ] && continue
  body=$(python3 -c "
import json,sys,os
print(json.dumps({'text':sys.argv[1],'reference_id':os.environ['FISH_VOICE_ID'],
                  'format':'wav','prosody':{'speed':1.1}}, ensure_ascii=False))" "$text")
  curl -s -X POST https://api.fish.audio/v1/tts \
    -H "Authorization: Bearer $FISH_API_KEY" -H "Content-Type: application/json" -H "model: s2-pro" \
    -d "$body" -o "narration/$id.wav"
  echo "$id $(ffprobe -v error -show_entries format=duration -of csv=p=0 narration/$id.wav)s  $text"
done < /tmp/lines.tsv
```

把每句的秒数记下来，下一步要用。

## 3. 拆故事：找贯穿符号

通读文案，为**每一句**找一个观众不用想就懂的具体符号。然后**收敛**——整条片子只留 2–3 个符号，每个用几次。

已验证有效的符号词典：

| 语义 | 符号 |
|---|---|
| 谁在哪、份额、从无到有 | 世界地图 + 图钉 + 标签 |
| 价格、代价、失衡 | 天平（一端实物，一端不断加码） |
| 排名、递进、还差多远 | 台阶 / 领奖台 |
| 数量、密集、庞大 | 一大堆实物（芯片、纸片、人群） |
| 时间点、正式性 | 翻牌板、印章、公文 |
| 被否定、被抹掉 | 一只手把东西撕走 / 白纸盖上 |

**收敛的价值**：观众第二次见到同一个符号就认得，第三次开始预判。三个符号反复用，比十五个各不相干的巧思强得多。

**收尾要让画面自己说结论**。例：镜头拉开，露出领奖台在已占的四格之上还有三格空着——"不是终点"不用旁白讲。

## 4. 拆画面：每句 2–3 镜，每镜一个不同的具体画面

这是最容易出错的一步。

**规矩**：

1. 每句旁白分 **2–3 个镜头**（1.2 秒以下的短句可以 1 镜）
2. 每镜是一个**具体的、可拍摄的画面状态**，不是一个概念
3. **相邻镜头的画面必须不同**——不同的物件、不同的景别、或同一物件的不同状态
4. 整条片子的画面构成**一条连续的视觉旅程**：这一镜的结束状态就是下一镜的开始状态

**画面推进的四种合法方式**（每一镜必须属于其中之一）：

| 方式 | 例子 |
|---|---|
| 物件变化 | 地图上零根图钉 → 一根 → 三根 |
| 景别变化 | 世界地图全景 → 推近到韩国 → 特写一个钉孔 |
| 状态变化 | 天平上几枚硬币 → 硬币堆成高塔 |
| 主体更替 | 地图退场 → 天平升起 |

**反例（实测失败，不要做）**：
- 连续三镜都是"一张空白纸加一条红线"，只是线长了一点
- 用同一张示意图配不同旁白
- 抽象几何图形代替实物

## 5. 拆节奏：分配镜长

某镜时长 =（该句配音时长 + 气口 0.18s）× 权重。

默认平均分。**三种情况不平均分**（实测有效）：

| 场景 | 权重 | 理由 |
|---|---|---|
| 开场钩子 | 62 / 38 | 第一个画面给足时间看清，第二镜甩快 |
| 递进关系 | 40 / 60 | 后一镜是结果，要压得住 |
| 收尾 | 35 / 65 | 最后一镜留 3–4.5 秒让观众消化 |

节奏原则见 [04-rhythm.md](./04-rhythm.md)。核心三条：**慢不等于静**、**全片都快等于没有快**、**节奏在剪辑台上定不在提示词里定**。

## 6. 产出逐镜表，交给用户过目

做成一张表，每行一镜：

| 镜 | 时长 | 旁白 | 画面 | 首尾帧 |
|---|---|---|---|---|
| W01 | 1.06s | 三点二八万亿。 | 满屏攒动人群 → 人群缩成小照片+贴纸 | A01+A02 |
| W02 | 0.65s | | 人群缩成小照片+贴纸 → 贴纸占满画面，四周账册 | A02+A03 |
| W03 | 1.53s | 这是上市当天的收盘市值。 | 贴纸+账册 → 交易所翻牌板翻动中 | A03+A04 |

**先自检，再给用户**：

```
关键帧张数 == 镜头数 + 1                    ✓/✗
任意两张关键帧的画面描述不重复                ✓/✗
每镜的 to 等于下一镜的 from（链不断）         ✓/✗
每句旁白都分到了镜头                         ✓/✗
全片符号种类 ≤ 3                            ✓/✗
黑场 ≤ 1 个且 ≤ 0.5 秒                      ✓/✗
```

自检全过之后，把表和自检结果一起发给用户，明确说：

> 这是逐镜表。现在改一版 5 分钟，跑完再改要 4 小时。有要否掉的镜头吗？

用户确认后才进入阶段 2。
