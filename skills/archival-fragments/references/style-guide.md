# 档案剪贴（Archival Fragments）视觉基线

视觉规则来自对 MiniMax《ARCHIVAL FRAGMENTS》全片 3458 帧的逐帧拆解，已用一条 34 镜完整成片验证（67.3s）。工作流是首尾帧，见 [02-keyframes.md](./02-keyframes.md)。

默认交付比例 **4:3**（2K 出 1920×1440）。参考片是 21:9，本模板不跟随。

母板不内置任何主角。这个风格靠**材质语言**统一画面，不靠角色——所以它天生适合没有贯穿人物的论述型内容。

## 第零条：具象优先

**纸、细红线、技术标注是「地面」，不是主体。** 站在上面的必须是具体的、观众一眼认得的实物。

把地面本身做成主角，画面会退化成图表——语义正确但观众要费力解码，三秒就划走。实测失败的例子：用空白纸加一条红线表达「这个位置是空的」，用三个黑方块表达「三家供应商」。

正确的做法是给每句话找一个通用符号（世界地图+图钉、天平、台阶、一大堆实物），一条片子收敛到三个，各用 2–5 次。详见 [02-keyframes.md](./02-keyframes.md)。

图片提示词里必须带这一句，否则模型会滑向图表化：

```
Everything is a real physical object photographed on paper — never a chart, never a diagram, never an infographic.
```

## 固定方向

- **一切都是"被拍下来的纸"。** 纸是画面的地面，不是背景板。撕边、胶带、翘起的纸角、纸上的短投影，都要有物理厚度。
- **主体一律单色印刷黑白。** 是印刷品的黑白（网点、油墨堆叠），不是摄影黑白。这条一破，画面立刻变成普通 AI 视频。
- **恰好一个强调色。** 一种暗砖红，只干四件事：细线、圆点/十字定位标、撕纸色块、小标签 chip。**红色永远不做主体**，面积永远小。
- **平光短影。** 不允许戏剧侧光、长投影、体积光、镜头光晕。这是最容易失守的一条，必须写进关键帧的风格前缀里。
- **留白 50–70%。** 构图是编辑排版逻辑，不是摄影构图逻辑。
- **运动是物件的运动。** 物件滑行、墨迹生长、纸张展开、硬币堆高。快慢不在这里定——见 [04-rhythm.md](./04-rhythm.md)，节奏由旁白时长和剪辑变速决定。

## 色板

| 职能 | 颜色 | 色值 |
|---|---|---|
| 纸底（画面的地面） | Ivory 冷象牙 | `#EDE7DC` |
| 印刷墨（主体、照片、水墨） | Ink 印刷黑 | `#1C1A17` |
| 中间调（半调网点、远景） | Warm Grey 暖灰 | `#8A8378` |
| 唯一强调 | Brick Crimson 暗砖红 | `#C8321E` |

约束：

- **色值只写在本文件里，不要写进提示词。** 提示词里写英文颜色名（`cool ivory paper` / `muted brick crimson`）。写十六进制会被模型当成画面里的文字画出来。
- 实测 H3 默认会把 crimson 渲成纯正红（接近 `#E8000F`），偏艳。提示词里必须写 `muted brick crimson, not pure red`，否则标签 chip 会跳出画面。
- 暖灰只作为纸与墨之间的过渡，不单独成为一个视觉元素。

## 红色的四种职责

除了这四种，红色不出现：

1. **贯穿细线**——一条手绘感的细红线，横穿画面。它是全片唯一的贯穿物，在不同镜里变成地平线、山脊、声波、地图路线、公路。
2. **定位标记**——小实心圆点、十字套准标（`⊕`），成对出现在线的两端或指向某处。
3. **撕纸色块**——不规则边缘的红色纸片，压在拼贴层下面。
4. **标签 chip**——扁平小矩形，白色无衬线大写字母，接一条细引线到一个实心圆点。

## 技术标注美学

画面里带一层"档案/片场文档"的标注，是这个风格可信度的来源。可用的标注词汇：

- 场记类：`SCENE 12B` `TAKE 06` `24 fps` `180°` `2.8` `5.6`
- 分析类：`SCALE` `SPACE` `GESTURE` `TEXTURE` `HIGHLIGHT` `CURVE` `DUST 01–05`
- 归档类：`REFERENCE` `ARCHIVE` `PLATE` `FIG. 3`

写法规则见 [03-shots.md](./03-shots.md)——**短词能出，长句必糊**。

## 图文字（image-in-type）

招牌手法：粗无衬线大写字母做遮罩，字腔里填不同的黑白影像。整片只用 2–3 次，每次都放在段落的重音上。单词必须短（≤11 字母），一屏最多三行。

## 关键帧不是「参考图」

早期版本写过「本模板不需要参考图」——那是文生视频路线下的结论，已作废。

现行工作流里每一镜都要两张图，但它们不是项目规则里说的「参考图」（用来锁主体一致性的 image2image 输入），而是**首尾帧**：直接决定镜头的起止状态。N 镜只需 N+1 张，因为相邻两镜共用同一个文件。

关键帧单独成表，结构见 `examples/keyframes.json`。
