# 一个空了十年的位置

风格：`archival-fragments` ｜ 目标时长 ≈ 72s ｜ 17 镜 ｜ 21:9

## 主张

这条片子不讲"长鑫市值第一"这条新闻——那是结果。它讲的是：**三点二八万亿定的不是长鑫今天的利润，是一个空了十年的位置终于有人站上去了。**

论点不由旁白直说，靠结构自己立：前四镜给数字并否定它，中段把"空位"建立起来，末镜回扣。

## 贯穿物

**一条红线 = 那条从零爬上来的份额曲线。**

它在每一镜变成不同的东西：零线 → 三家公司之间的分割线 → 开始爬升的曲线 → 股价的跳空缺口 → 产能曲线 → 最后延伸出画面。全片只有这一个贯穿元素。
