# Changelog

## 2.0.0 — 2026-08

从「风格提示词包」升级为**端到端成片工作流**。

### 新增

- **阶段 0 环境准备**（`00-setup.md`）：ffmpeg / LibTV CLI / Fish Audio 的安装命令与七项检查清单。凭据验证是真的发一次 TTS 请求再量时长，不是只看变量填没填；LibTV 验登录 + 验两个模型权限。全绿才提示用户可以开始。
- **阶段 1 拆分镜**（`01-script.md`）：想法 → 主张 → 短句文案 → 配音量时长 → 拆故事（符号词典）→ 拆画面（画面推进的四种合法方式）→ 拆节奏 → 逐镜表 + 六项自检 → 交用户过目。
- **阶段 5 生成与合成**（`05-produce.md`）：出图、审图、跑样片、跑全量、变速拼片、混音、验收的全套命令，含两个必然踩到的坑。
- 八张连续关键帧示例（`assets/example-01..08-*.jpg`），直观展示画面如何一张一张推进。
- 成本要点：H3 最短 5 秒而每镜只用 1–3 秒，素材/成片比约 2.5×。

### 修复

- **防止「全片一张图」**。1.x 的说法「相邻两镜共用同一张图」会被误读成「整片共用一张图」，实际导致过整条片子几十个镜头画面雷同的翻车。现在写成硬约束加自检，并明确 `style-reference.png` 只给人看、绝不作为生成输入。
- 推翻早期的节奏结论。「慢—慢—慢—爆发」加「一镜一个静止状态」被实测证伪（逐帧变化率只有参考片的 1/34），改为：慢不等于静、全片都快等于没有快、节奏在剪辑台上定。
- 移除所有脚本文件，改为文档内的可复制命令。
